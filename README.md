# Technest

Technest is a dynamic web application built using PHP with an MVC (Model-View-Controller) architecture. This project demonstrates a clean separation of concerns in web development and uses HTML, CSS, JavaScript, and PHP for full-stack functionality.

## 🚀 Features

- Organized MVC architecture
- User-friendly interface
- Dynamic page rendering
- Easy to maintain and extend
- Responsive design using CSS
- Basic interactivity with JavaScript

## 📁 Project Structure

technest/
   controllers/ # Handles user input and interactions
    models/ # Interacts with the database and data logic
    views/ # Contains UI templates and page structure
    index.html # Landing page
    assets/ # CSS, JS, images, etc.
    README.md # Project documentation
